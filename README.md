# Apple Stock Data Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on historical Apple stock market data using Python.

The dataset contains daily stock information including Open, High, Low, Close, Adjusted Close, and Volume values.

## 🎯 Objectives

* Load and understand Apple stock data
* Explore the structure of the dataset
* Check data types and missing values
* Remove duplicate records
* Generate statistical summaries
* Understand stock price and trading volume information

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab

## 📂 Dataset

The dataset used in this project is **Apple Stock Data**.

It contains **10,409 records** and **7 columns**:

| Column    | Description             |
| --------- | ----------------------- |
| Date      | Trading date            |
| Open      | Opening stock price     |
| High      | Highest stock price     |
| Low       | Lowest stock price      |
| Close     | Closing stock price     |
| Adj Close | Adjusted closing price  |
| Volume    | Number of shares traded |

The dataset covers historical records from **1980 to 2022**.
